# Software Installation Request

Category: Software
Severity: Low
Keywords: install, software, application, request, admin rights, license

## Symptoms
- User needs a new application installed.
- Installer shows "Administrator permission required".

## Troubleshooting Steps
1. Check whether the software is available in the Company Portal / Software Center.
2. If available, install it directly from there.
3. If not available, raise a software request with the business reason.
4. Do not download software from unknown websites.

## Permitted Actions
- create_ticket(category="Software")

## When to Escalate
- Software is not on the approved list (needs security approval).
- Admin rights or a paid license is required.

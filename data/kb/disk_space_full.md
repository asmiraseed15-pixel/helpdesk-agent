# Disk Space Full

Category: Hardware
Severity: Low
Keywords: disk full, storage, low disk space, c drive, no space, cleanup

## Symptoms
- Windows shows "Low disk space" warning.
- Apps cannot save files or install updates.

## Troubleshooting Steps
1. Open Settings > System > Storage to see what uses space.
2. Run Disk Cleanup and delete temporary files.
3. Empty the Recycle Bin.
4. Delete old files from the Downloads folder.
5. Uninstall unused applications.
6. Move large files to the company cloud drive.

## Permitted Actions
- create_ticket(category="Hardware")

## When to Escalate
- Disk is still more than 90 percent full after cleanup.
- Disk needs an upgrade.

# Windows update stuck
Category: Software
Keywords: update stuck, windows update, installing updates
Severity: Medium

## Symptoms
Update is stuck at a percentage.

## Troubleshooting Steps
1. Wait at least 30 minutes.
2. Restart the laptop.
3. Run the Windows Update troubleshooter.
4. Free disk space and retry.

## Permitted Actions
- run_update_troubleshooter(device_id)
- create_ticket(category="Software")

## When to Escalate
- Update fails again with the same error code.

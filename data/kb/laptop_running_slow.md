# Laptop Running Slow

Category: Hardware
Severity: Low
Keywords: slow, laptop, lag, hang, performance, high cpu, freezing

## Symptoms
- Laptop takes a long time to start or open apps.
- Apps freeze or respond slowly.
- Fan runs loudly all the time.

## Troubleshooting Steps
1. Restart the laptop (many users never shut down for days).
2. Open Task Manager (Ctrl+Shift+Esc) and check which app uses high CPU or memory.
3. Close unused apps and browser tabs.
4. Disable unnecessary startup apps from Task Manager > Startup.
5. Check free disk space (keep at least 15 percent free).
6. Run Windows Update and install pending updates.
7. Run a full antivirus scan.

## Permitted Actions
- create_ticket(category="Hardware")

## When to Escalate
- Laptop is still slow after all steps.
- Laptop is more than 4 years old or shows hardware errors.
